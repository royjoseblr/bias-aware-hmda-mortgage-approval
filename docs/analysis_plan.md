# Analysis Plan by Research Question

## RQ1: Predictive performance
Compare logistic regression, random forest, and XGBoost under the same train/test split and preprocessing framework.

## RQ2: Demographic disparities
Produce outcome-rate tables and chi-square tests for race, ethnicity, and sex. Report statistical parity difference and disparate impact ratio relative to a documented reference group.

## RQ3: Explainability
Use coefficient direction for logistic regression, model feature importance for tree models, and SHAP for global and local explanations.

## RQ4: Bias mitigation
Compare the selected baseline model with reweighting and threshold optimization. Assess changes in ROC-AUC, F1, statistical parity difference, and disparate impact ratio.
